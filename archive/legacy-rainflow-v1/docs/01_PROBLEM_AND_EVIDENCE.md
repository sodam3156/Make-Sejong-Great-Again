# 문제 정의와 근거

## 1. 고객

### 1차 고객

세종시 교통 운영·신호 최적화 실무자와 도시통합정보센터 운영자

### 이해관계자

- 세종시와 행복청
- 세종경찰청·경찰서
- 한국도로교통공단
- LH 및 기존 구축·유지보수 사업자
- 출퇴근 운전자, 대중교통 이용자, 보행자
- 긴급차량 운영기관

## 2. 특정 상황

출퇴근, 사고, 행사, 공사, 기상 변화 등으로 한 교차로의 정체가 인접 교차로로 번질 때 운영자는 여러 화면과 장비 상태를 함께 보고 신호 운영안을 빠르게 판단해야 한다.

## 3. 핵심 문제

> 기존 ITS 인프라와 개별 실증은 존재하지만, 여러 교차로의 데이터를 통합해 정체 파급을 예측하고, 안전한 신호 후보안을 만들고, 운영자가 근거를 확인해 승인하고, 적용 효과를 검증하는 하나의 운영 흐름이 부족하다.

## 4. 관찰된 구조적 원인

| 원인 | 결과 |
|---|---|
| 구축 주체와 운영 주체의 분리 | 인수 후 장비·서버·소프트웨어 책임 공백 |
| 하드웨어 중심 유지보수 | 통신·동기화·관제 소프트웨어 문제 장기화 |
| 장비 세대와 인터페이스 차이 | 하나의 제어 계층으로 묶기 어려움 |
| 안전·책임 규정 | AI 산출안을 곧바로 현장에 적용할 수 없음 |
| 연 단위 조사·용역 중심 최적화 | 돌발 정체에 대한 빠른 폐루프 대응이 어려움 |
| 성과 검증의 단절 | 개선 수치가 도시 전체 시민 체감으로 이어지는지 불명확 |

## 5. 확인된 팩트

### 기반 인프라와 실증

- 국토교통부는 2020년 세종 1생활권에 스마트교차로 14개소와 스마트횡단보도 10개소를 적용하는 실증을 소개했다.
- 스마트교차로는 센서·CCTV·신호제어 시스템으로 교통정보를 수집하고 실시간 신호제어를 목표로 했다.
- 세종은 C-ITS와 자율주행 대중교통 실증 경험도 갖고 있다.

### 운영 공백

- 2025년 보도와 세종시의회 자료에서는 LH로부터 이관된 행복도시 346개 교차로 광자가망 기반 온라인 신호제어 시스템의 실시간 원격제어 문제가 제기됐다.
- 보도상 원인 후보는 도시통합정보센터 서버·저장장치 노후화, 현장 제어기와의 데이터 동기화 중단이다.
- 돌발 정체나 중요 행사 시 현장에서 신호를 수동 조작하는 사례가 언급됐다.
- 유지보수 예산이 주로 신호등·기둥 등 하드웨어 보수에 사용됐고, 소프트웨어 원인 규명은 뒤늦게 추진된 것으로 보도됐다.

## 6. 아직 확인이 필요한 것

다음 항목은 관계기관 자료 또는 현장 인터뷰 없이 확정하면 안 된다.

- 2026년 7월 현재 원격제어 장애가 해소됐는지
- 온라인 제어기 총수 346개와 366개 집계 차이의 기준
- “236개 불량”의 불량 유형과 현재 복구율
- 스마트교차로 14개소의 현재 운영 범위와 실제 제어 방식
- 사용 가능한 실시간 데이터 필드, 갱신주기, 보유기관
- 제어기 제조사·프로토콜·경찰청 표준규격 호환성
- 한누리대로 등 후보축의 교차로별 신호계획과 교통량
- 시뮬레이션 보정에 필요한 실측 지체·대기행렬 자료

## 7. 문제의 강도

### 빈도

출퇴근 정체와 신호 대기는 매일 반복된다.

### 심각도

시간 손실뿐 아니라 긴급차량 지연, 보행 안전, 교차로 꼬리물기, 운전자 불만과 연결된다.

### 대안의 한계

- 내비게이션은 우회 경로를 제시하지만 신호 운영 자체를 개선하지 않는다.
- 정기 신호 최적화 용역은 돌발 상황에 즉시 대응하기 어렵다.
- 단일 교차로 감응제어는 인접 교차로로 번지는 정체를 충분히 다루지 못한다.
- 완전 자동제어는 안전·책임·표준 연동 장벽이 높다.

### AI가 필요한 이유

- 여러 교차로와 시간대의 상태를 함께 추론해야 한다.
- 정체·보행·긴급·장비 상태가 서로 충돌하는 다목적 문제다.
- 운영자에게 후보안의 이유와 위험을 짧게 설명해야 한다.
- 단, 최종 안전 제약은 LLM이 아니라 결정론적 규칙과 최적화 코드로 보장해야 한다.

## 8. 프로젝트 문제 문장

> 우리는 세종의 교통 운영자가 돌발 정체와 출퇴근 혼잡 상황에서 여러 교차로의 단절된 데이터를 일일이 해석하고 안전한 신호안을 빠르게 판단하기 어려운 문제를, 다중 관점 AI 분석·결정론적 안전 가드·운영자 승인·디지털 트윈 효과검증이 결합된 교통제어 오케스트레이터로 해결한다.
