# 공개 교통방향 → RainFlow 모델 접근로 매핑 후보

이 디렉터리는 월간 교통량의 `동·서·남·북` 열을 RainFlow 접근로 ID와 연결하기 위한 **검토 후보**를 보존한다.

## 근거

공공데이터포털 설명은 자료를 `동, 서, 남, 북 교차로 통행방향별` 교통량이라고 설명하고, 컬럼을 각각 `동쪽 교통량`, `서쪽 교통량`, `남쪽 교통량`, `북쪽 교통량`이라고 정의한다.

- 공식 자료: https://www.data.go.kr/data/15113448/fileData.do
- 수정일: 2025-09-05

RainFlow 저장소의 화면 라벨은 모델 suffix를 진입로 위치로 표현한다.

- `R1_N`: 성금교차로 북측 진입로
- `R1_W`: 성금교차로 서측 진입로
- `R2_S`: 청사교차로 남측 진입로
- `R3_E`: 세종교차로 동측 진입로

따라서 공개자료가 **차량 진행방향**을 뜻한다는 해석 아래 다음과 같이 반전한다.

| 진입로 위치 | 차량 진행방향 | 공개자료 열 |
|---|---|---|
| 북측 | 남향 | 남 |
| 서측 | 동향 | 동 |
| 남측 | 북향 | 북 |
| 동측 | 서향 | 서 |

## 현재 후보

| 모델 접근로 | 공개자료 열 | 강건 비중 | 상태 |
|---|---|---:|---|
| R1_N | 성금 `남` | 0.312042 | 검토 필요 |
| R1_W | 성금 `동` | 0.206793 | 검토 필요 |
| R2_S | 청사 `북` | 0.346572 | 검토 필요 |
| R3_E | 세종 `서` | 0.173056 | 검토 필요 |

이 비중들은 각 교차로 내부 방향구성이다. 네 접근로 사이의 절대 수요 비율이 아니다.

## 내부 회랑 라벨 주의

`R2_N`과 `R3_N`은 화면에서는 북측 진입로로 표시되지만 시뮬레이터 계산에서는 각각 상류 링크 `L12`, `L23`의 선두 통과 흐름을 서비스하는 내부 라벨이다. 외부 도착수요인 `BASE_DEMAND` 항목이 아니므로 공개 월간 방향열과 직접 매핑하지 않는다.

## 승인 전 금지

- 후보표를 근거로 `BASE_DEMAND`를 즉시 변경
- 월간 방향비중을 차량/5초 값으로 사용
- 진행방향에 좌회전·직진·우회전이 포함된 구성을 단일 진입로 신규수요로 간주
- 세종교차로 2022-08 서 방향 856대를 정상값으로 사용

최종 매핑에는 공공데이터 제공기관의 방향 정의 확인 또는 교차로별 검지기 배치·방향 코드가 필요하다.
