# Make Sejong Great Again

> **센서는 이미 있다. 이제 도시가 판단하게 만들 차례다.**

세종 행복도시의 기존 ITS·스마트교차로 인프라 위에서 교통 데이터를 통합하고, 여러 AI 관점이 신호 운영안을 검토한 뒤, 안전 규칙과 운영자 승인을 거쳐 적용 후보안을 만드는 **AI 다교차로 교통제어 오케스트레이터** 프로젝트입니다.

이 프로젝트는 실제 신호기를 해커톤에서 직접 제어한다고 주장하지 않습니다. 실제 운영의 핵심인 **수집 → 상태판단 → 최적화 → 안전검증 → 운영자 승인 → 효과검증**의 끊어진 고리를 디지털 트윈으로 시연합니다.

## 한 문장 문제 정의

> 세종 행복도시는 광통신망·온라인 신호제어기·스마트교차로를 구축했지만, 노후 장비와 단절된 운영 소프트웨어 때문에 다교차로 데이터를 실시간으로 연결해 안전하게 신호를 최적화하고 효과를 검증하는 폐루프 운영이 어렵다.

## 우리가 만드는 것

- 5~10개 교차로의 실시간 상태를 보여주는 운영자 대시보드
- 교통 흐름·보행 안전·긴급차량·장비 상태 관점의 AI 분석
- 신호안별 예상 지체시간·대기행렬·정지율 비교
- 보행 최소시간과 충돌 신호를 차단하는 결정론적 안전 가드
- AI 제안 → 운영자 승인 → 디지털 트윈 적용 → 전후 효과검증 흐름
- 왜 이 안을 제안했는지 재현 가능한 의사결정 로그

## 해커톤 MVP

실데이터 연동이 없더라도 재현 가능한 시뮬레이션 데이터로 다음 장면을 3분 안에 보여줍니다.

1. 한누리대로형 간선축에 돌발 정체가 발생한다.
2. AI가 인접 교차로의 파급을 예측한다.
3. 여러 관점의 에이전트가 대안을 평가한다.
4. 안전 가드가 위험한 안을 자동 탈락시킨다.
5. 운영자가 근거와 예상효과를 보고 승인한다.
6. 디지털 트윈에서 적용 전후 KPI가 즉시 비교된다.

### 외부 컴퓨터 실행 계약

제출 심사본은 Windows x64 압축파일을 푼 뒤 `start.bat` 한 번으로 로컬 서버와 브라우저가 실행되어야 한다. Node, Python, SUMO, API 키, 인터넷 연결을 요구하지 않는다. 프론트 정적 빌드와 FastAPI 백엔드를 하나의 실행파일에 포함하고, 교통 결과는 사전 계산 fixtures를 기본값으로 사용한다. 개발 재현 경로는 `docker compose up --build`로 별도 제공한다.

외부 PC 통과 기준은 `start.bat` 실행 후 60초 이내 화면 표시, 정상에서 복구 결과까지 3분 흐름 완주, 재실행 시 포트 충돌 없음, 한글 경로와 공백 경로에서 실행, 인터넷 차단 상태 동작, LLM·SUMO 미설치 상태 동작이다.

## 프로젝트 원칙

- **안전이 최적화보다 우선한다.**
- AI는 신호 현시를 직접 결정하지 않고 후보안을 제안한다.
- 보행 최소시간·상충 현시·비상 복귀는 코드로 강제한다.
- 실측 사실, 보도·회의록, 팀의 추론, 향후 목표를 구분한다.
- “도시 전체 실시간 자동제어가 이미 된다”는 과장 표현을 쓰지 않는다.
- 해커톤에서는 실제 제어기가 아니라 디지털 트윈과 승인 워크플로를 시연한다.
