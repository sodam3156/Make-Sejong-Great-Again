# TATS 픽셀 사운드 패키지 V2

Unity 적용 경로: `unity/TATSGame/Assets/TATS`

- UI: 24 kHz·10~11bit 느낌으로 가장 거칠게 처리
- 액션: 32 kHz·12bit 느낌으로 조작감과 무게 유지
- 경고: 약한 32 kHz·12bit 처리로 정체·보행·충돌 구분 우선
- 배경: 48 kHz 스테레오 유지, 낮은 음량으로 장시간 피로 억제
- 저장 형식: GitHub 배포판은 Unity 지원 OGG(Vorbis)

Mini Motorways 실제 음원이나 외부 샘플은 사용하지 않았으며, 절차적 도시 사운드 설계 방식만 참고했습니다.
