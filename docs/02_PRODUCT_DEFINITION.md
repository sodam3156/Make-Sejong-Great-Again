# 제품 정의

## 1. 제품명

**Make Sejong Great Again**

설명형 부제:

> 세종형 운영자 승인 AI 교통제어 오케스트레이터

## 2. 가치 제안

### 운영자에게

여러 교차로의 상태와 장비 이상을 하나의 화면에서 보고, AI가 제안한 신호안의 근거·위험·예상효과를 비교해 승인할 수 있다.

### 지자체에게

새 센서를 대규모로 설치하기 전에 기존 인프라의 활용도를 높이고, 어떤 구간에 장비 교체나 예산이 필요한지 근거를 얻는다.

### 시민에게

신호 최적화가 실제로 몇 분의 지체와 몇 회의 정지를 줄였는지 투명하게 확인할 수 있다.

## 3. 핵심 기능

### A. 교차로 상태 통합

- 교통량, 속도, 대기행렬, 신호 현시
- CCTV·검지기 데이터 신선도
- 통신 지연, 제어기 상태, 결측치
- 인접 교차로 정체 파급 위험

### B. 다중 관점 AI 검토

| 관점 | 역할 |
|---|---|
| 흐름 최적화관 | 평균 지체와 대기행렬 최소화 |
| 보행 안전관 | 보행 최소시간·교통약자·횡단 대기 보호 |
| 긴급 대응관 | 긴급차량·사고·행사 우선순위 검토 |
| 인프라 진단관 | 센서·통신·제어기 신뢰도 평가 |
| 정책·운영관 | 적용 범위, 책임, 설명 가능성 검토 |

AI 에이전트는 자유 토론만 하지 않는다. 각자 동일한 후보안에 점수와 근거를 제출하고, 구조화된 합의 절차로 비교한다.

### C. 안전 가드

- 상충 현시 금지
- 최소 녹색·황색·전적색 시간 강제
- 보행 최소시간 강제
- 주기·분할·오프셋 변경폭 제한
- 데이터가 오래됐거나 장비 상태가 불명확하면 적용 차단
- 통신 실패 시 기존 안전 신호계획으로 복귀

### D. 운영자 승인

- 제안 이유와 신뢰도
- 적용 전후 예상 KPI
- 영향 교차로와 보행 영향
- 승인, 거절, 보류, 파라미터 수정
- 모든 결정의 감사 로그

### E. 적용 후 검증

- 기준안 대비 평균 지체
- 최대·평균 대기행렬
- 정지율과 통행시간
- 보행 대기와 안전 제약 위반
- 예측효과와 실제효과 차이

## 4. 대표 사용자 흐름

1. 운영자가 “한누리대로 남행 정체 급증” 알림을 받는다.
2. 시스템은 정체가 2개 인접 교차로로 번질 확률과 장비 신뢰도를 표시한다.
3. AI가 세 가지 신호 후보안을 만든다.
4. 안전 가드는 보행 최소시간을 위반한 후보안을 제거한다.
5. 운영자는 남은 안의 예상효과와 부작용을 비교한다.
6. 운영자가 승인하면 디지털 트윈에 적용된다.
7. 15분·30분 후 KPI와 예측 오차가 자동 기록된다.

## 5. 차별점

| 기존 접근 | 본 프로젝트 |
|---|---|
| 단일 교차로 최적화 | 간선축·다교차로 파급 고려 |
| AI 추천만 제시 | 안전 가드와 운영자 승인 포함 |
| 좋은 조건의 데모 | 결측·노후 장비·통신 장애까지 표현 |
| 결과 수치만 제시 | 왜 채택·탈락했는지 결정 과정 시각화 |
| 한 번의 최적화 | 적용 후 효과검증과 학습 루프 |
| 실제 제어를 과장 | 디지털 트윈·섀도 모드부터 단계적으로 확장 |

## 6. 제품의 핵심 장면

가장 중요한 화면은 화려한 지도 자체가 아니다.

> “AI가 18% 개선안을 제시했지만, 보행 안전관과 안전 가드가 이를 거부하고 13% 개선안을 최종 추천하는 장면”

이 장면은 이 프로젝트가 단순한 최적화 알고리즘이 아니라 공공 안전 운영 시스템이라는 점을 보여준다.

## 7. 성공 기준

- 운영자가 30초 안에 문제 교차로와 원인을 파악한다.
- 후보안 생성부터 안전 검증까지 10초 이내에 완료한다.
- 기준 TOD 대비 시뮬레이션 평균 지체를 의미 있게 줄인다.
- 보행·상충 현시 안전 위반은 0건이다.
- 모든 제안·거절·승인·적용 결과를 재현할 수 있다.
