# MVP 범위와 시연

## 1. MVP 목표

실제 신호기 연동이 아니라, **운영자가 믿고 검토할 수 있는 AI 신호 운영 제안 시스템**의 핵심 흐름을 증명한다.

## 2. 반드시 구현할 범위

### 데이터·시뮬레이션

- 5개 교차로로 구성된 가상 간선축
- 정상, 출퇴근 혼잡, 사고 차로폐쇄 3개 시나리오
- 교통량·속도·대기행렬·신호 현시 생성
- 장비 1개 통신 지연 또는 센서 결측 이벤트

### 분석·추천

- 현재 상태 요약과 정체 파급 예측
- 2~3개 신호 후보안 생성
- 흐름·보행·긴급·장비 관점 평가
- 안전 가드 통과 여부
- 최종 추천안과 설명

### 운영 UI

- 교차로 지도 또는 축 다이어그램
- KPI 카드와 시간 추세
- AI 검토 패널
- 적용 전후 비교
- 승인·거절 버튼
- 결정 로그

## 3. 제외 범위

- 실제 세종시 신호제어기 쓰기 연동
- 실시간 CCTV 영상 전체 분석
- 도시 전체 교차로 디지털 트윈
- 강화학습 모델의 실도로 안전성 주장
- 경찰·지자체 승인 없이 자동 적용
- 실제 시민 통행시간 개선률 주장

## 4. 3분 데모 시나리오

### 0:00–0:25 문제 제시

“세종은 346개 교차로 온라인 신호제어 인프라와 스마트교차로를 갖췄지만, 실시간 원격제어와 운영 소프트웨어 공백이 제기됐습니다.”

화면에는 5개 교차로가 정상 상태로 보인다.

### 0:25–0:55 돌발 정체 발생

사고로 한 차로가 막히고 대기행렬이 인접 교차로까지 늘어난다. 시스템은 장비 신뢰도와 정체 전파 위험을 표시한다.

### 0:55–1:35 AI 후보안 비교

- 안 A: 지체 18% 감소 예상, 보행 최소시간 위반으로 탈락
- 안 B: 지체 13% 감소 예상, 안전 가드 통과
- 안 C: 지체 8% 감소 예상, 긴급차량 통과에 유리

각 에이전트의 찬반과 근거가 짧게 표시된다.

### 1:35–2:10 운영자 승인

운영자는 안 B를 선택한다. 승인 전 변경되는 주기·분할·오프셋과 영향을 받는 교차로를 확인한다.

### 2:10–2:40 효과 검증

디지털 트윈이 적용 전후를 비교한다. 평균 지체, 최대 대기행렬, 정지율이 개선되고 안전 위반은 0건으로 표시된다.

### 2:40–3:00 결론

“우리는 AI가 신호를 마음대로 바꾸게 하지 않습니다. 기존 세종 인프라 위에 AI 판단, 안전 규칙, 사람의 승인, 효과검증을 연결합니다.”

## 5. 데모용 KPI

| KPI | 기준 |
|---|---|
| 평균 지체시간 | 기준 TOD 대비 감소 |
| 최대 대기행렬 | 상류 교차로까지 넘치지 않게 관리 |
| 정지율 | 기준 대비 감소 |
| 보행 평균대기 | 악화 한도 설정 |
| 안전 제약 위반 | 반드시 0 |
| 추천 생성시간 | 10초 이내 |
| 운영자 판단시간 | 30초 이내 |
| 데이터 신선도 | 임계치 초과 시 자동 적용 차단 |

수치는 시뮬레이션 결과임을 화면과 발표에서 명시한다.

## 6. MVP 완료 정의

- 새 환경에서 한 명이 실행 절차에 따라 데모를 시작할 수 있다.
- 세 시나리오가 같은 입력 시 재현된다.
- 안전 위반 후보안이 항상 탈락한다.
- 승인 없이는 적용 상태로 넘어가지 않는다.
- 결과 화면에 시뮬레이션임이 표시된다.
- 모든 결정 로그를 JSON 또는 DB에서 조회할 수 있다.
