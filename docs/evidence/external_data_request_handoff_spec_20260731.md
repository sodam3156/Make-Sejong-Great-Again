# 외부 교통·신호·회랑자료 요청 및 수령 검수 명세

- 기준 상태일: 2026-07-29 KST
- 상태 근거: 사용자 확인 정보공개포털
- 현재 공통 상태: 부서 및 부서처리자 지정 중
- 목적: 기관 회신을 받았을 때 필요한 파일과 검수조건을 즉시 식별하고, 미확인 자료가 모델값으로 자동 승격되는 것을 방지

## 1. 추적 요청

| 우선순위 | request_id | 핵심 목적 |
|---|---|---|
| P0 | `IR-CORRIDOR-LATEST` | 세 교차로 시간대별 교통량, 차로·저장공간, 속도·통행시간 및 조건부 신호자료 |
| P1 | `IR-TRAFFIC-2025` | 2025년 방향·시간대 교통량 원자료 |
| P1 | `IR-TRAFFIC-2026` | 2026년 최신 방향·시간대 교통량 원자료 |
| P2 조건부 | `IR-SIGNAL-CHANGE-2026` | 신호체계 변경 이력과 교란요인 확인 |
| P2 조건부 | `IR-SIGNAL-OPS-2026` | 실제 신호모델을 범위에 넣을 경우 운영계획 입력 |

신호자료는 현재 합성 큐 모델의 즉시 필수 입력이 아니다. 실제 신호계획 재현 또는 신호 서비스율 보정을 주장할 때만 필수다.

## 2. 사용자가 지금 확인할 것

정보공개포털에서 다섯 건의 **현재 상태 문구와 확인일**만 확인한다.

- 계속 `부서 및 부서처리자 지정 중` 또는 `처리 중`이면 추가 파일은 필요 없다.
- `이송`이면 이송기관명만 기록한다.
- `공개` 또는 `부분공개`이면 회신 공문과 첨부파일 원본을 받는다.
- `비공개` 또는 `정보 부존재`이면 결정문을 원본 그대로 보존한다.

접수번호, 로그인 정보, 담당자의 개인 연락처는 공개 저장소에 기록하지 않는다.

## 3. 회신 도착 시 제공할 것

1. 회신 공문 원본
2. 첨부파일 원본 전체
3. 포털 상태와 확인일
4. 파일명이 바뀌었다면 원래 파일명
5. 개인정보가 보이는 화면은 가린 사본

원본 데이터의 행을 삭제하거나 엑셀 값을 수정하지 않는다. 잘못된 값은 원본 보존 후 정규화 단계에서 flag로 처리한다.

## 4. 교통량 수령 최소조건

절대수요나 동일 날짜 보정 후보가 되려면 다음이 확인돼야 한다.

- 조사 날짜와 시간대
- 5분·15분·시간 중 실제 집계주기
- KST 여부
- 교차로 식별자와 좌표
- 방향열이 접근방향인지 진행방향인지
- 가능하면 회전별 교통량
- 단위와 차종 포함범위
- 결측·중복·보정·품질 flag
- 원본 SHA-256과 공개범위

월간 합계만 있으면 방향비중 맥락으로만 사용하고 `BASE_DEMAND` 절대값으로 변환하지 않는다.

## 5. 차로·저장공간 수령 최소조건

- 방향별 차로 수
- 차로 이용구분
- 전용차로 및 유효 대기길이
- 정지선 위치
- 교차로 사이 실제 사용 가능 길이
- 버스전용차로·차로감소·주정차 등 제약

이 조건이 없으면 표준노드링크의 링크 길이를 바로 `storage_veh`로 환산하지 않는다.

## 6. 신호자료 수령 최소조건

실제 신호모델을 주장하려면 다음이 한 세트로 필요하다.

- 적용 시작일·종료일
- 주기
- 현시 순서
- 방향별 유효녹색
- 황색·전적색 등 소거시간
- 옵셋
- TOD 계획 또는 감응제어 조건
- 시설 식별자와 단위

2023년 분류자료만으로 2026년 현재 신호계획을 만들지 않는다.

## 7. 수령 후 처리 순서

1. 개인정보 제거 전 원본은 비공개 작업공간에 보존
2. 공개 가능한 원본의 SHA-256 계산
3. `data/public/information_requests/<request_id>/raw/`에 원본 저장
4. 기관·회신일·기준일·공개범위 manifest 작성
5. 정규화본을 별도 디렉터리에 생성
6. 단위·시간대·공간·결측·중복·이상치 검사
7. 허용 용도와 금지 주장을 기록
8. 별도 adapter PR과 독립검토 전에는 `synthetic-v0` 유지

## 8. 자동 검증

```bash
python scripts/validate_external_data_request_catalog.py \
  data/governance/external_data_request_catalog.json

python -m pytest backend/tests/test_external_data_request_catalog.py -q
```

이 검증은 요청·수령 절차의 누락과 보안상 잘못된 기록을 막는다. 기관이 회신했다는 사실이나 수치의 정확성을 대신 확인하지는 않는다.
