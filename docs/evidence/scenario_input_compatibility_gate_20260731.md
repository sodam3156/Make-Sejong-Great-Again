# 시나리오 입력 호환성 검증 게이트

- 담당 범위: 근거·KPI·팩트체크·QA
- 목적: 서로 다른 연도·해상도·자료등급의 근거가 모델 입력 또는 현장 재현 주장으로 잘못 승격되는 것을 차단
- 비목적: 교통용량, 수요, 신호 서비스율, 공정성 또는 안전 임계값의 산정·승인

## 현재 허용 조합

현재 예시 manifest는 다음 조합만 허용한다.

- 기상: 기상청 세종 지점 239의 2022-08-10 1분 관측을 날씨 시계열 입력으로 사용
- 교통: 2022-05~2023-03 월간 방향별 합계를 방향비중 맥락으로만 사용
- 신호: 2023년 자료를 역사적 분류로만 사용하고 실제 신호계획 입력으로 사용하지 않음
- 공간망: 2026년 표준노드링크를 시설 식별·연결성에만 사용
- 건조 대조일: 2022-07-27, 분석 시작 06:00 KST 이후에 한해 당일 자료만으로 직전 6시간 검증

따라서 현재 시나리오의 정확한 표현은 **관측 날씨 시계열이 결합된 관측 제약 합성 시나리오**이며, 동일 날짜 교통과 신호가 결합된 현장 재현은 아니다.

## 자동 실패 규칙

`validate_scenario_input_compatibility.py`는 다음을 실패 처리한다.

1. ERA5 proxy를 관측 날씨 또는 직접 모델 입력으로 표시
2. 시나리오 날짜가 교통자료 기간 밖에 있음
3. 월간 방향별 합계를 같은 날짜 교통량 또는 절대 `BASE_DEMAND` 보정값으로 사용
4. 2023년 신호자료를 2026년 현재 운영계획으로 표시
5. 공간망 자료로 역사적 운영상태를 추론
6. 동일 날짜 교통·신호 없이 field replay를 주장
7. 2022-07-26 자료 없이 건조 대조 분석을 06:00 이전에 시작

## 실행

```bash
python scripts/validate_scenario_input_compatibility.py \
  data/observed/derived/scenario_input_manifest.example.json
```

오류가 있으면 종료코드 `1`, 통과하면 `0`을 반환한다. `backend/tests/test_scenario_input_compatibility.py`가 허용·금지 조합을 회귀검사한다.
