## 2. 345·346·약 366·236의 관계

### 2.1 직접 확인된 원문

1. 2020년 행복청 준공 발표는 U-City 2단계 2차 사업에서 **온라인 신호제어 345개소**를 신규 구축했다고 기록한다.
2. 2025-12-15 세종시의회 보도자료는 **346개 교차로**에 광자가망 기반 온라인 신호제어 시스템을 구축해 2020년 8월 LH로부터 이관받았다고 적는다.
3. 2026-02-03 교통국장 답변은 LH로부터 1~4생활권 **온라인 신호제어기 약 366개**를 인수했고, 2025년 말부터 2026년 1월 말까지 조사한 결과 **236개가 불량**이었다고 밝힌다.

### 2.2 가장 안전한 해석

- `345개소`: 2020년 준공 당시 서비스 설치 지점 또는 시설 개소 수
- `346개 교차로`: 2025년 의원이 표현한 교차로 단위
- `약 366개 제어기`: 2026년 집행부가 실태조사 대상으로 파악한 장비 단위

이는 **단위 차이에 기반한 추론**이다. 공개된 자산 ID 대조표가 없으므로 다음 계산은 금지한다.

- `346 - 345 = 신규 교차로 1개`
- `366 - 346 = 교차로당 추가 제어기 20개`
- `236 / 366 = 현재 장애율 64.5%`
- `366 - 236 = 현재 정상 제어기 130개`

`약 70%`와 `236/366=64.48%`도 일치하지 않는다. 분모가 구두 근삿값이고 불량 판정의 중복·유형이 공개되지 않았기 때문이다.

## 3. 2026년 7월 원격제어 복구 여부

### 확인

- 2025-12-15 공식 의회 보도자료: 센터 서버·저장장치 노후화와 현장 제어기 데이터 동기화 중단으로 시스템을 거의 활용하지 못하고 있다고 지적했다.

## 6. 실시간·동적 신호 API 조사

### 6.1 전국 통합 실시간 신호 API

- 제공기관: 행정안전부·한국지역정보개발원
- 등록: 2026-03-12, 수정: 2026-04-06
- Base URL: `apis.data.go.kr/B551982/rti`
- `GET /crsrd_map_info`: 교차로 맵 정보
- `GET /tl_drct_info`: 제어기 기준 8방향별 점등상태·잔여시간
- 자동승인, 개발계정 5,000회
- 제공기관은 실제 신호와 처리 지연 차이가 있을 수 있으므로 참고용 사용을 권고한다.

### 6.2 경찰청 신호 개방 데이터

2026-05 등록된 경찰청 LINK 데이터는 교차로 정적 기반정보, 현시 구성, TOD 계획정보, 시그널 맵을 제공한다고 설명한다. 그러나 현재 설명상 수집 대상은 **인천·대구 광역시**다. 세종 3개 교차로의 2026 계획 확인 근거로 사용할 수 없다.

### 6.3 이번 조사에서 표본 호출하지 못한 이유

전국 통합 API는 서비스키가 필요하다. 조사 시점인 2026-07-30에는 공공데이터포털 전환 작업으로 7월 29일 19:00부터 8월 2일 18:00까지 신규 활용신청과 인증키 신규 발급·관리가 제한된다. 기존 키를 가진 경우 호출은 가능하지만, 저장소나 대화에 사용할 수 있는 키가 제공되지 않았다.

따라서 `API 존재·필드·엔드포인트`는 확인, `세종 수록·세 교차로 응답·결측·지연`은 미확인이다.

## 8. 2026년 대상 교차로 신호계획 변경

세종시는 도로교통공단과 매년 교통 신호 체계 최적화 용역을 수행하고, 주요 교차로의 LOS·혼잡도 조사를 연 2회 실시한다고 설명했다. 과거 자료에는 민원·경찰 요청과 교통량 분석을 바탕으로 TOD를 작성·수정하는 절차도 확인된다.

그러나 공개 검색에서는 다음을 찾지 못했다.

- 2026년 성금·청사·세종교차로 신호계획 번호
- 요일·시간대별 현시·주기·옵셋
- 변경 전후 적용일과 승인기관
- 세 교차로가 2026 최적화 대상에 포함됐다는 목록

따라서 `IR-SIGNAL-CHANGE-2026`은 **재검토 필요 / 기관 또는 경찰·도로교통공단 자료 필요** 상태다.

> 대상 세 교차로는 2023년 공개자료상 지역연동 고정시간 신호교차로이며, 2026년 현재 신호계획은 별도 확인이 필요하다.
