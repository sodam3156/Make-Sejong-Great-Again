## 1. 즉시 적용되는 금지 주장

다음 문장은 독립 검토와 현장 보정이 끝나기 전까지 화면, 발표 대본, README, 심사 답변에서 사용하지 않는다.

1. 성금·청사·세종교차로가 회전교차로라는 주장
2. 현재 모델이 세 교차로의 실제 신호 운영을 재현한다는 주장
3. 우천 시 실제 진입용량이 모델의 계수만큼 감소한다는 주장
4. `corridor_gating`이 실제 절재로에서 제시된 비율만큼 혼잡·지체를 개선한다는 주장
5. `FAIRNESS_P95_LIMIT_PCT = 15.0`이 세종시 또는 교통공학 표준에 의해 검증된 임계값이라는 주장
6. 합성 run의 교차로별 P95 지체·점유율·대기열·저장공간을 실측값처럼 읽는 주장
7. 대상 구간의 신호제어를 직접 또는 자동으로 변경할 수 있다는 주장

허용되는 표현은 다음으로 제한한다.

> 실제 표준노드링크의 지명·위치·연결관계를 표시 기준으로 사용하고, 신호운영을 모델링하지 않은 합성 큐 시뮬레이션에서 가상의 우천 용량 저하와 정책 후보를 비교하는 오프라인 의사결정 프로토타입이다.

## 3. 신호 미모델링 한계

현재 결정론적 큐 모델은 다음을 계산하지 않는다.

- 신호 주기, 현시, 옵셋, 감응·연동 제어
- 차로군별 포화교통류율과 회전교통량
- 황색·전적색, 보행현시, 대기행렬 방출파
- 버스 우선신호, 긴급차량 우선, 실제 제어기 프로토콜
- TTC·PET 등 궤적 기반 안전지표

따라서 실제 지명을 사용하더라도 결과는 **신호교차로 운영 성능 예측**이 아니다. 발표에서는 “신호 미모델링 합성 큐 비교”라는 한계를 첫 결과 화면과 최종 결과 화면에 모두 유지한다.

## 5. 독립 검토자와 역할 분리

- **시우(근거·KPI):** 원자료, 문헌 적용 범위, 보정표 근거를 제출한다. 자신의 값에 대한 최종 승인자는 될 수 없다.
- **최영(AI·백엔드):** `simulation.py`, `safety.py`, 파라미터 및 가드 구현을 독립 검토하고 행별 `ACCEPT/REVISE/REJECT`와 이유를 기록한다.
- **준(PM·제품):** 방법론 승인자가 아니라 제출 범위와 금지 주장이 화면·대본·문서에 일치하는지 확인한다.
- **프론트/디자인:** `provisional`, `synthetic`, `signal-not-modeled` 고지가 결과 화면에서 식별 가능한지 확인한다.

최영의 이름·날짜·근거가 없는 상태에서는 “독립 검토 완료”로 표시하지 않는다. PM 확인만으로 기술 검토를 대체하지 않는다.

## 6. 승인·기각 기준

### 승인 가능

모든 조건을 만족해야 한다.

1. 보정표 전 행에 검토자·날짜·근거 링크·결론이 있다.
2. `REVISE` 항목은 코드·fixture·문서가 같은 변경에서 재동결됐다.
3. `REJECT` 항목은 제출 경로와 발표 대본에서 제거됐다.
4. seed 1~10과 두 우천 시나리오에서 결과 방향이 재현되고, 실패 seed도 숨기지 않는다.
5. `python -m pytest backend/tests -q`와 `python scripts/generate_contract_artifacts.py --check`가 병합 문맥에서 통과한다.
6. 실제 지명과 합성 수치의 구분이 화면·대본·README에 중복 고지된다.

### 즉시 기각

다음 중 하나라도 해당하면 방법론 승인을 기각한다.

- 회전교차로 문헌을 실제 대상 신호교차로의 직접 성과 근거로 제시
- 합성 수치를 실측 또는 2026년 현재 운영 성과로 제시
- 독립 검토자 없이 provisional 값을 확정값으로 변경
- `+15%` 공정성 한도를 외부 표준으로 표시
- 실패 seed·가드 위반 정책을 숨기거나 평균값만 제시
- PR #35보다 먼저 병합해 정본 문서와 실제 지명 경계를 다시 불일치시킴
