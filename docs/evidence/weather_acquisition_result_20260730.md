## 2. 원본·처리 산출물

```text
data/observed/weather_reference/
├─ observed/normalized/          # 최소화된 AWS 강수필드 CSV.gz와 ASOS 시간 CSV
├─ observed/kma_observation_manifest.json
├─ processed/kma_weather_scenario_inputs.csv.gz
├─ processed/dry_candidate_screening.csv
└─ weather_source_manifest.json
```

원본 API 응답은 인증키를 제외해 로컬 검증하고 SHA-256만 manifest에 보존한다. 저장소에는 재현에 필요한 강수필드만 최소화해 커밋한다. `kma_weather_scenario_inputs.csv.gz`에는 우천일과 건조일을 각각 5분·15분 구간으로 집계한 관측 강수 입력값이 들어 있다. 이 파일은 강우 시계열 입력용이며 교통용량 감소계수나 수요배율을 포함하지 않는다.

## 4. ERA5 proxy와의 차이

ERA5 proxy는 2022-08-10을 `36.7 mm`로 나타냈지만 세종 239 공식 관측은 `139.3 mm`였다. 따라서 proxy는 후보 선별·민감도 참고용으로만 유지하고, 우천 시계열 입력은 KMA 관측자료를 사용한다.

## 5. 모델 반영 한계
