## 2. 최초 실행 오류와 처리

최초 실행은 `models=era5_land`를 요청했다. 해당 응답의 시간·일 강수량이 전부 `null`이었지만 스크립트가 `null`을 `0.0`으로 치환해 네 날짜를 모두 건조 후보로 잘못 통과시켰다.

이 결과는 폐기했다.

수정 내용:

1. 강수 변수를 제공하는 `ERA5`로 변경
2. `null` 한 건이라도 있으면 실행 실패

4. 시간 강수 합과 일 강수 합 교차검사
5. 분석기간을 우천일 전후 28일로 확대
6. 건조·같은 요일·같은 달·날짜거리 순으로 후보 자동 정렬

## 5. 현재 막힌 지점

기상청 API허브의 ASOS 시간자료는 발급 인증키가 필요하다. 현재 저장소 Actions secret에 `KMA_API_AUTH_KEY`가 없어 workflow manifest에 공식자료가 `NOT_FETCHED`로 기록됐다.

또한 최종 목표인 분자료는 기상자료개방포털에서 한 번에 하루씩 조회·다운로드해야 하며 QC 플래그까지 보존해야 한다.

시우가 완료한 것:

- 공식 관측지점과 날짜 범위 정의
- 보조자료 실제 획득
- 결측 오판 발견·수정
- 건조 후보 우선순위 산출
- 원본·처리파일·manifest·재현 workflow 제출

저장소 관리자 또는 기상청 계정 권한이 필요한 것:

- Actions secret `KMA_API_AUTH_KEY` 등록 또는 KMA 원본 파일 제공

공식 KMA 입력이 도착하기 전에도 독립적으로 진행 가능한 다음 과업은 기존 세종 교통량 CSV의 전처리다.
