## CI 동작

Workflow는 proxy 수집을 별도 artifact로 생성하고, 커밋된 최소화 KMA 강수자료를 다시 검증한다. 재생성한 ASOS 시간 CSV·scenario CSV·manifest에 `git diff`가 생기면 실패한다. 최소화된 AWS 강수 CSV.gz와 ASOS 시간 CSV를 이용해 scenario와 manifest를 재생성한다. 인증키나 자동 커밋 권한은 사용하지 않는다.

## 남은 제한

- 건조 대조일의 직전 6시간 검증은 분석 시작이 06:00 KST 이후일 때만 현재 자료로 완결된다.
- 동일 날짜의 시간대별 교통량이 없으므로 강우–교통 반응계수는 보정할 수 없다.
- 신호주기·현시·옵셋이 없으므로 실제 신호운영 재현을 주장할 수 없다.

ERA5는 계속 proxy로 유지하며 KMA 관측값과 혼합해 하나의 관측자료처럼 표현하지 않는다.
