## 2. 의도적으로 하지 않은 것

### 월간 교통량의 5·15분 분해

월간 합계를 타지역 시간형상으로 나누면 수학적으로 합계는 보존되지만, 다음 가정이 추가된다.

- 특정 평일의 일교통량
- 시간대 분포
- 15분 내 분포
- 접근로와 통행방향의 대응
- 회전비율

이 과정은 현재 시뮬레이터를 현장 보정 상태로 만들지 못하고 오히려 가정 범위만 넓힌다. 따라서 런타임 입력은 만들지 않는다. 필요하면 향후 `monthly-constrained synthetic`이라는 별도 합성 시나리오로만 구현한다.

### 부산 큐·LOS API

외부 신호교차로 adapter 시험에는 유용하지만 세종 대상 회랑의 수요·신호·큐를 검증하지 못한다. 현재 기능 완성의 필수 의존성이 아니므로 후순위로 미룬다.

### 정밀도로지도 객체를 즉시 저장공간으로 변환

다음이 해결되기 전에는 기존 `22/18` 저장공간 상수를 교체하지 않는다.

1. `R1_N`, `R1_W`, `R2_S`, `R3_E` 및 내부 흐름을 정확한 HD-map 진입 링크에 연결
2. 직진·좌회전·우회전 및 겸용차로 판독
3. 정지선부터 어느 상류 지점까지를 저장길이로 볼지 규칙 승인
4. 차량당 정지점유길이와 차로별 사용 가능 길이 민감도 정의
5. 독립 검토자가 지도와 결과를 재현

## 4. 여기서 멈추는 필수 블로커

다음은 기능을 현장 보정 시뮬레이션으로 완성하려면 없어서는 안 된다.

1. **동일 날짜 5·15분 접근방향·회전별 교통량**
2. **적용일이 명확한 현재 신호계획**: 주기, 현시순서, 유효녹색, 황색, 전적색, 옵셋, TOD
3. **대상 회랑 실제 큐·지체·LOS 또는 링크 속도·통행시간 검증자료**
4. **정확한 모델 접근로↔HD-map 링크 매핑과 독립 검토**

1~3은 외부기관 자료 또는 현장조사가 필요하다. 4는 현재 원본만으로 후보표를 만들 수 있지만, 런타임 변경 전 팀의 독립 검토와 승인이 필요하다.
