## 1. 질문과 결론

### 타지역 또는 2~3년 전 자료 사용이 금지되는가

**일률적으로 금지되지 않는다.** 자료의 시간·공간 대표성에 따라 허용 용도가 달라진다.

| 근거 수준 | 허용 용도 | 금지 용도 |
|---|---|---|
| 대상 교차로의 최신 현장자료 | 현장 보정, 실제 운영 성능 검증 | 수집 범위를 넘어선 도시 전체 일반화 |
| 국내 공식 편람·동일 시설유형 실측연구 | 초기값 범위, 민감도 스윕, 보수적 스트레스 시나리오 | 세종 현장 승인값 또는 현재 실측값으로 표시 |
| 타지역·과거 동일 시설유형 연구 | 외부 타당성 범위, 방향성 교차검토 | 절재로 대표값·예상 개선율로 표시 |
| 다른 시설유형 연구(회전교차로 등) | 정성적 메커니즘 가설 | 신호교차로의 직접 용량계수·성과 근거 |
| 순수 합성값 | UX·QA·실패경로 재현 | 교통공학 표준 또는 현장 권고값 |

따라서 문제는 “오래됐거나 타지역이라서 전부 폐기”가 아니라, **전이근거를 현장 대표값으로 승격하는 것**이다.

## 2. 신호교차로에 직접 맞는 국내 근거

### 2.1 한국 도로용량편람 반영 연구

김봉석·노창균·손봉수(2015)는 서울의 도시부 십자형 신호교차로 3개 지점에서 2011~2012년 주간 CCTV·현장 영상과 기상청 강우자료를 결합해 포화차두시간을 측정했다.

- 0~2 mm/h 미만: 강우보정계수 `0.93` — 약 7% 감소
- 2~4.5 mm/h 미만: `0.83` — 약 17% 감소
- 4.5 mm/h 이상: `0.79` — 약 21% 감소

논문은 이 산정방안이 한국 도로용량편람 2013의 신호교차로 강우 영향 산정에 반영됐다고 설명한다.

- KCI/DOI: https://doi.org/10.7470/jkst.2015.33.1.90
- 도로용량편람 2013 공식 원문 안내: https://www.codil.or.kr/detailAnwGuide.do?nserialno=1092

### 2.2 보조 국내 범위

강우·밝기·중차량 구성비를 함께 고려한 국내 신호교차로 연구에서는 강우에 따른 교통용량 감소가 약 `5.3%~21.8%` 범위로 나타났다. 이는 단일 고정값보다 조건별 범위를 사용해야 한다는 보조 근거다.

- KCI: https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART000926628

### 2.3 전이 한계

위 값은 세종 성금·청사·세종교차로에서 측정한 값이 아니다. 차로수, 좌·우회전 비율, 중차량, 보행 상충, 현시·주기·옵셋, 포화교통류율이 다르면 같은 강우에서도 결과가 달라진다.

FHWA도 신호교차로 용량은 포화교통류율과 유효녹색시간 비율의 곱이며, 포화교통류율은 시공간에 따라 변하므로 가능한 경우 지역 자료를 수집해야 한다고 명시한다.

- https://www.fhwa.dot.gov/publications/research/safety/04091/07.cfm
- https://ops.fhwa.dot.gov/publications/fhwahop18036/chapter5.htm

따라서 위 국내 계수는 **세종 실측 보정값이 아니라 신호교차로용 전이 범위**다.

## 3. 현재 구현과 근거의 차이

현재 `simulation.py`는 다음 값을 쓴다.

```python
RAIN_CAPACITY_FACTOR = {
    "dry": 1.00,
    "light": 0.95,
    "moderate": 0.89,
    "heavy": 0.84,
}
```

현재 값은 국내 신호교차로 편람 반영 구간 `0.93 / 0.83 / 0.79`보다 완만하고, 강우량 `mm/h`와 연결되지 않는다. 또한 기존 문서의 주 근거는 회전교차로 임계간격·후속차두 연구다.

### 시우 근거 판정

- 현재 값을 “문헌 평균으로 검증된 세종 계수”라고 표현: **REJECT**
- 현재 값을 이름 없는 합성 스트레스 밴드로 유지: **DEMO-ONLY 가능**
- 신호교차로 문헌과 정렬하려면 강우량 구간을 명시하고 `0.93 / 0.83 / 0.79`를 민감도 기준으로 사용: **REVISE 권고**
- 실제 절재로 성능 예측에 사용: **현장 보정 전 REJECT**

최종 코드 변경·승인은 독립 검토자와 PM의 범위 결정 사항이며, 본 문서는 근거와 QA 판정을 제공한다.

## 4. 재현 방법

현재 `simulation.py`와 `policies.py` 로직을 그대로 재현하고 다음 조건만 교체했다.

- 시나리오: `rain_spillback_a`, `rain_spillback_b`
- 정책: `no_action`, `fixed_metering`, `corridor_gating`
- seed: 각 `1~10`
- 총 실행: 강우 프로파일 4종 × 시나리오 2종 × seed 10개 × 정책 3종
- KPI: spillback wall-clock, 모형 내 누적 체류시간, 최악 진입로 P95 proxy, guard 통과
- 프로파일:
  - 현재: moderate `0.89`, heavy `0.84`
  - 국내 저강우: `0.93`
  - 국내 중강우: peak `0.83`
  - 국내 고강우: transition `0.83`, peak `0.79`

이 검증은 코드 구현의 계산 재현 및 민감도 QA이며 현장 검증이 아니다.

## 5. 강우계수 민감도 결과

표의 `spill seed`는 무대응에서 spillback이 발생한 seed 수다. `Δ TTT`는 무대응 대비 `corridor_gating`의 누적 체류시간 중앙값 변화다.

| 프로파일 | 시나리오 | spill seed | 무대응 spill 중앙값 | gating spill 중앙값 | gating Δ TTT 중앙값 | gating guard | fixed guard |
|---|---|---:|---:|---:|---:|---:|---:|
| 현재 0.89→0.84 | A | 10/10 | 1,950초 | 0초 | -77.1% | 10/10 PASS | 0/10 PASS |
| 현재 0.89→0.84 | B | 10/10 | 2,392.5초 | 0초 | -69.1% | 10/10 PASS | 0/10 PASS |
| 국내 저강우 0.93 | A | **0/10** | 0초 | 0초 | 0.0% | 10/10 PASS | 0/10 PASS |
| 국내 저강우 0.93 | B | 10/10 | 2,035초 | 0초 | -82.9% | 10/10 PASS | 0/10 PASS |
| 국내 중강우 0.83 | A | 10/10 | 1,947.5초 | 0초 | -75.9% | 10/10 PASS | 0/10 PASS |
| 국내 중강우 0.83 | B | 10/10 | 2,325초 | 0초 | -67.6% | 10/10 PASS | 0/10 PASS |
| 국내 고강우 0.79 | A | 10/10 | 2,285초 | 0초 | -69.4% | 10/10 PASS | 0/10 PASS |
| 국내 고강우 0.79 | B | 10/10 | 2,487.5초 | 0초 | -61.1% | 10/10 PASS | 0/10 PASS |

### 핵심 해석

1. **A 시나리오의 문제 발생 자체가 강우계수에 민감하다.** 저강우 `0.93`에서는 10개 seed 모두 spillback이 발생하지 않았다.
2. `corridor_gating`의 100% spillback 제거는 여러 고강우 조건에서 반복되지만, 이는 단순 큐 구조와 정책 규칙의 특성이다. 실도로 기대효과로 읽으면 안 된다.
3. 중·고강우에서 정책 방향은 유지되지만 Δ TTT는 약 `-61.1%~-75.9%`로 달라진다. 절대 개선율은 파라미터 의존적이다.
4. 저강우 A에서 `fixed_metering`은 spillback이 없는 상황에서도 누적 체류시간을 중앙값 약 `+962.9%` 악화시켰고 전 seed에서 가드가 거절했다. 이 정책은 실제 대안이 아니라 실패경로 QA fixture로만 적합하다.

## 6. 핵심 파라미터 추가 민감도

국내 고강우 프로파일(`0.83→0.79`)에서 다음을 1요인씩 변경했다.

- 게이팅 시작점: `0.75 / 0.80 / 0.85`
- 게이팅 하한: `0.25 / 0.35 / 0.45`
- capacity drop: `0.60 / 0.70 / 0.80`
- 링크 저장공간: 현재값의 `80% / 100% / 120%`

두 시나리오·seed 1~10에서 `corridor_gating`은 전부 guard를 통과하고 spillback 0초를 유지했다. 그러나 누적 체류시간 개선 중앙값은 조건에 따라 다음 범위로 변했다.

- A: 약 `-60.5%~-75.0%`
- B: 약 `-51.7%~-67.5%`

### 판정

- 정책 방향성: 테스트 범위에서 **ROBUST**
- 100% spillback 제거와 절대 개선율: **현장 대표성이 없는 모델 산출값**
- gate threshold/floor, capacity drop: **DEMO-ONLY / 독립 검토 필요**
- 저장공간 22대·18대: 실제 차로·유효길이 없이 **PENDING**

## 7. 공정성 15% 임계 민감도

`FAIRNESS_P95_LIMIT_PCT`를 `10 / 15 / 20 / 30 / 50 / 100%`로 바꿔 같은 seed·시나리오를 재판정했다.

- `corridor_gating`: 모든 임계값에서 전 seed PASS
- `fixed_metering`: 모든 임계값에서 전 seed FAIL
- fixed metering의 최대 진입로 악화:
  - 현재 프로파일 A: 약 `875%~1,059%`
  - 현재 프로파일 B: 약 `394%~478%`
  - 국내 고강우 A: 약 `458%~504%`
  - 국내 고강우 B: 약 `271%~303%`

따라서 `15%`는 현재 동결 시나리오의 정책 선택을 바꾸는 임계점이 아니다.

### 시우 공정성 판정

- `15%`를 세종시·법정·교통공학 표준이라고 주장: **REJECT**
- 위험한 고정 미터링을 의도적으로 탈락시키는 내부 데모 가드: **DEMO-ONLY 유지 가능**
- 현재 시나리오의 정책 순위가 15%에 과적합됐다는 우려: 이번 스윕에서는 **낮음**
- 이해관계자 합의 또는 현장 분포 없이 최종 운영한도로 승인: **PENDING**

FHWA의 일부 15% 기준은 모델-관측 교통량·통행시간 보정 오차 예시이지, 진입로 간 공정성 악화 허용기준이 아니다.

- https://ops.fhwa.dot.gov/trafficanalysistools/tat_vol3/sect5.htm

## 9. 화면·대본 허용 문장

> 한국 도로용량편람에 반영된 국내 신호교차로 강우 보정 범위를 참고해 민감도를 시험했으며, 현재 결과는 세종 현장자료로 보정하지 않은 신호 미모델링 합성 큐 시뮬레이션이다.

> 약한 강우 가정에서는 혼잡이 발생하지 않는 경우도 확인됐으므로, 화면의 개선율은 실제 절재로 기대효과가 아니라 선택한 스트레스 시나리오 내 결과다.

- 독립 기술 리뷰 서명
- 실제 절재로 현장 보정 완료 선언
- PR #35·#37 병합과 제출 범위 최종 결정

독립 검토자는 본 문서의 재현 조건을 확인한 뒤 PR #37 보정표에 이름·날짜·근거와 `ACCEPT / REVISE / REJECT`를 기록해야 한다.
