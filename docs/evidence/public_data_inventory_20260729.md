## 1-1. 표준노드링크 공간망 확보 (2026-07-29 추가)

`nodelink_202607291508.csv`가 공간망이 아닌 집계표로 판정된 문제를 해소하기 위해 실제 노드·링크 공간망을 추가 확보했다.

- **원본**: 국가교통정보센터 [노드링크 자료실](https://www.its.go.kr/nodelink/nodelinkRef)의 `[2026-07-16]NODELINKDATA.zip`(2026-07-16까지 반영된 전국표준노드링크·회전제한정보·링크부가정보). [다운로드 URL](https://www.its.go.kr/opendata/nodelinkFileSDownload/DF_218/0), 로그인 불필요.
- 전국 원본 ZIP은 257MB(269,698,831 bytes)라 GitHub 용량 제한 때문에 커밋하지 않는다. SHA-256 `adfb23b31592d264cfbc48458ae0fdb5daee707e8c7ba4dbced53c7c544c1a48`. 구성: `MOCT_NODE.shp` 계열(전국 약 117만 노드), `MOCT_LINK.shp` 계열(약 155만 링크), `MULTILINK.dbf`, `TURNINFO.dbf`, `내역서.csv`. 좌표계는 ITRF2000 중부원점 TM(.prj), DBF 인코딩 CP949.
- **추출**: [`scripts/extract_sejong_nodelink.py`](../../scripts/extract_sejong_nodelink.py)가 세종 지역코드 `413`(NODE_ID/LINK_ID 접두)으로 필터해 EPSG:4326 GeoJSON을 생성한다. 지역코드는 세 교차로명을 전국 노드에서 전수 검색해 확인했고, 세종 bbox 재검증에서 예외 0건. 재실행 시 동일 SHA-256이 나오는 결정론적 스크립트이며, 노드·링크 수와 세 교차로명 존재를 assert로 내장한다.
