RainFlow Sejong - 실행 안내
==============================

이 폴더에는 오프라인으로 동작하는 RainFlow Sejong 제출본이 들어 있습니다.
인터넷, Node.js, Python, SUMO, API 키 없이 실행됩니다.

60초 실행법
-----------
1. 압축을 전부 해제합니다 (RainFlowSejong.exe, _internal 폴더를 포함한 전체).
   한글이나 공백이 섞인 폴더 경로에서도 동작합니다.
2. start.bat 을 더블클릭합니다.
3. 콘솔에 사용 포트가 표시되고, 서버가 뜰 때까지(최대 55초) 자동으로 기다립니다.
4. 준비가 끝나면 기본 브라우저가 http://127.0.0.1:<포트>/ 로 자동으로 열립니다.
5. start.bat 을 다시 실행해도 안전합니다. 기존 서버가 살아 있으면 그대로 재사용하고,
   그렇지 않으면 새로 시작합니다.

종료법
------
1. stop.bat 을 더블클릭합니다.
2. 직전에 start.bat 이 기록한 프로세스가 실제로 RainFlowSejong 인지 확인한 뒤에만
   종료합니다. 다른 프로그램이 같은 번호(PID)를 재사용 중이면 종료하지 않고
   기록만 정리합니다.

포트 충돌 시 대처
------------------
- start.bat 은 운영체제에 사용 가능한 포트를 요청해서 사용하므로 보통 충돌이
  발생하지 않습니다.
- 이전 실행이 비정상 종료되어 runtime\rainflow.port 값이 남아 있어도, 그 포트의
  서버가 응답하지 않으면 새 포트를 골라 다시 시작합니다.
- 55초 안에 서버가 응답하지 않으면 logs 폴더의 server-*.out.log, server-*.err.log
  파일을 확인하세요.

Windows SmartScreen 경고 대응
------------------------------
서명되지 않은 실행 파일이므로 "Windows에서 PC를 보호했습니다" 경고가 뜰 수 있습니다.
1. 경고 창에서 "추가 정보"를 클릭합니다.
2. "실행" 버튼을 클릭합니다.

백신 프로그램이 오탐(false positive)으로 실행을 막는 경우, PyInstaller onedir
빌드 특성상 발생할 수 있는 알려진 현상입니다. 예외 처리 후 다시 실행하세요.

문제가 발생하면
----------------
logs 폴더(런처와 서버 출력)와 _internal\backend\logs 폴더(시뮬레이션/승인 감사
기록)를 함께 보존해 전달하세요.
